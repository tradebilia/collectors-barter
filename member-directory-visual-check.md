# Member Directory visual verification

The Member Directory was checked at desktop and mobile widths after adding provider marks to account-verification badges. eBay, Facebook, LinkedIn, and Etsy badges now have compact recognizable letter marks that remain readable and wrap cleanly on mobile.

A keyboard-focusable help icon appears beside Account verifications. Its tooltip explains that account verification confirms a connected external account, while Verified Merchant is a separate Tradebilia-reviewed designation. Existing separate merchant badges, collecting interests, and username privacy behavior remain intact.

# Member Directory visual verification

The `/members` route was visually checked at desktop and mobile widths after removing public usernames and adding collecting-interest labels. Member cards no longer show the @username line. The intentional username search field and profile navigation remain present.

The cards now show “Collecting interests” with the explanatory text “Categories this collector has selected.” Members with stored selected categories display all available selected category chips instead of the “Multi-category collector” fallback. Verified Merchant remains a separate badge beside the display name. At 390px wide, the category chips wrap inside the card without horizontal overflow.

# Tradebilia Category Page Benchmark

The **Sports Cards** page is now the working benchmark for the next category-page refinement pass. Its purpose is not to make every category look the same. Instead, it establishes a shared structural rhythm that the other categories can inherit while still keeping their own color systems, typography, and collector-specific personality.

## Benchmark rules

| Layer | Benchmark rule | How to apply to other categories |
| --- | --- | --- |
| Hero section | Keep the category logo, eyebrow, headline, description, and market summary in a tighter composition so browsing content begins sooner. | Preserve each category’s distinct art direction, but avoid oversized hero media that delays the first actionable content. |
| Right-side hero support | Pair the headline block with a purposeful support card or notes panel that explains the market tone. | Replace the Sports Cards “show floor notes” language with category-specific framing, such as grading notes, franchise signals, or rarity guidance. |
| Quick actions | Add a small set of category-specific shortcut chips near the hero or filter rail to make the page feel curated. | Use chips that fit the category vocabulary, such as publishers for comics or set eras for Pokémon. |
| Filter rail | Use the left rail as the consistent browsing anchor with search first, then category-specific filters, then subscriber tools. | Keep the order and hierarchy stable so users learn the pattern once and recognize it everywhere. |
| Summary panel | Use a compact curated-exchange summary with sort and secondary navigation aligned tightly beside it. | Reuse the same structural layout while swapping copy and accent treatment per category. |
| Editorial support row | When live inventory is thin, use a small editorial or spotlight row to keep the page visually alive and to demonstrate the collectible tone. | Populate with real or mapped imagery relevant to the category instead of leaving the page visually empty. |
| Empty state | The empty state should redirect users toward other meaningful discovery paths instead of stopping at “no listings.” | Include category-aware copy plus links to inventory, members, or nearby marketplace actions. |
| Trust language | Make subscriber-only and trust-building actions visible without overwhelming the browse experience. | Keep Watchlist, trade, and ratings cues present, but adapt emphasis to the category’s collector behavior. |

## Sports Cards-specific elements to keep category-specific

The Sports Cards page includes several details that should **not** be copied verbatim to every other page. The teal-and-cream palette, the “show floor notes” framing, and the rookie-card editorial language are intentionally specific to Sports Cards. These should be translated into each category’s own equivalent rather than reused directly.

## Reusable implementation intent

The benchmark should now be treated as a **layout model** rather than a one-off visual exception. As the remaining category pages are refined, the implementation should favor shared composition patterns where possible, with each category swapping in its own theme data, shortcut vocabulary, and spotlight content.

## Rollout audit notes

The first comparison pass confirms that **Comics** still uses the older category-page structure. Relative to Sports Cards, it lacks the tighter benchmark support panel in the hero, the category-specific shortcut chips, the richer curated-summary blocks, and the more purposeful standby treatment when listings are sparse. This makes Comics the clearest next candidate for adopting the shared benchmark structure while preserving its own crimson editorial identity.

The **Vintage Toys** page now shows the benchmark structure much more clearly than the earlier Comics state: the tighter hero is in place, the summary card is stronger, and the new support section has begun to appear beneath the summary area. This suggests the broader rollout is taking hold, but the remaining pages still need explicit verification one by one before the all-category audit can be considered complete.

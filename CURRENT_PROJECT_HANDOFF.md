

## eBay Active current-value evidence (2026-10-13)
Confirmed visual matches from the optional bounded eBay Active image review are now represented as **current-value market evidence** in the shared Evidence Review ledger. They appear in the source’s `Items sent to analyzer` panel with price and identity-review provenance, while remaining distinct from completed-sale valuation candidates. Unmatched active listings remain context-only. The current-value bucket is explicitly asking-price evidence, not a completed sale, so it must not be presented as sold-comps evidence or silently blended into completed-sale medians. The eBay Active visual-review result is lifted into the same parent Evidence Review data path so the provider panel and summary do not disagree. Added normalization and UI regressions; no database writes, migrations, provider credential changes, or public-domain publication.



## Explicit zero-result marketplace fallbacks — November 2, 2026
Mercari and TCGplayer now execute a bounded fallback sequence when the primary marketplace query returns zero usable records. The clean item-title fallback runs before any metadata-only fallback, so a movie cannot fall back first to an illogical query such as `1997 mint Blu-ray`. Results are deduplicated, executed queries and per-query counts are returned for audit, and the Test AI panel visibly reports when fallback search was used. eBay Active and eBay Sold-Comps already had bounded fallback execution and were left unchanged. Focused fallback, shared-query, and UI tests passed 125/125; TypeScript and production build passed; diff hygiene passed. No database, migration, seed, destructive, credential, provider, deployment, or publishing changes were made. P0 safeguards, existing custom database protections, read-only database baseline, universal filters, one ranking score, valuation gates, and `object-contain` image rendering remain preserved.
